# Core Below

Оригинальный браузерный прототип асимметричной кооперативной игры для трех игроков.

## Запуск

```powershell
node server.mjs
```

Откройте `http://localhost:4173`.

## Как играть

- При первом запуске онлайн закрыт до короткого одиночного обучения. За одну учебную аварию игрок автоматически пробует наблюдателя, архивариуса и оператора; прогресс сохраняется в браузере.
- Онлайн-смену запускает командир комнаты после подключения оператора, наблюдателя и архивариуса. Если командир выходит, управление передается следующему игроку.
- Во время онлайн-смены новые подключения в комнату запрещены, даже при свободной роли или для наблюдателя. После победы или поражения вход снова доступен. Обучение работает независимо от этого ограничения. Восстановление участия после обрыва по подтвержденному Telegram ID и голосовая интеграция хаба пока не реализованы.
- Каждая смена проходит в одной из трех локаций: биореакторе, криохранилище или узле дальней связи. Сценарии не повторяются, пока команда не увидит весь набор.
- Смена длится до четырех минут и состоит из четырех случайных аварий: голодный реактор, течь, перегрузка, пожар или убежавшая бомба.
- Наблюдатель получает показания трех узлов и нормальный диапазон. Он находит отклонение, выбирает неисправный узел и расшифровывает рисунок сигнала по короткой легенде. Цель не раскрывается заранее другим ролям.
- Оператор идет к диагностированному узлу на WASD или стрелках и читает режим его терминала (+ или −). Эти данные доступны только на месте; их нужно передать архивариусу.
- Архивариус не может писать свободные сообщения. Его справочник содержит три правила, а не готовый ответ: строка выбирается по коду наблюдателя, столбец по режиму оператора. Найденный инструмент передается символом.
- Оператор подключает инструмент. Затем наблюдатель ловит безопасную область движущегося индикатора давления и дает команду «Сейчас». У оператора есть 2,2 секунды на запуск ремонта; пропущенное окно можно поймать снова.
- Наблюдатель закреплен у пульта, видит полную карту, отслеживает оператора и направляет его стрелками. Его аудиоканал отключен. В онлайне готового маршрута на карте оператора нет: маяк виден только вблизи цели.
- При каждом новом происшествии меняются узел, показания, рисунок сигнала, режим терминала и соответствия правил. Обучение проводит через тот же цикл с автоматическим переключением ролей и сохраняет позицию оператора.
- Неверное действие вызывает короткую помеху: пар, мигание света, скользкий пол или ложную тревогу. Финальный взрыв происходит только после шести сбоев либо окончания общего времени.
- Локации меняют фон, названия станций и музыкальный профиль, а набор аварий перемешивается между сменами.
- Ошибки, действия, шаги, связь, победа и поражение сопровождаются звуковыми эффектами; звук отключается кнопкой в HUD.
- Личная статистика открывается отдельно из меню, HUD или итогового экрана. Она хранит победы, серии, сценарии, роли, время, ошибки, связь и историю смен под собственным ключом браузера.
- На мобильном устройстве игра просит повернуть телефон горизонтально, разворачивает арену на весь экран и оставляет только компактные ролевые панели и экранные стрелки.

## Автоматическая проверка

При запущенном сервере:

```powershell
node tests/stats.test.mjs
node --test tests/party-rules.test.mjs
node tests/lobby-smoke.mjs
node tests/party-smoke.mjs
```

`party-smoke.mjs` проходит обучение, полноценную смену из четырех аварий, ошибки диагноза и кода, неверную синхронизацию, пропущенное окно запуска и финальное поражение. `party-rules.test.mjs` проверяет 200 вариантов правил и цикл давления.

Проект использует только встроенные модули Node.js и не требует установки зависимостей.

## Публикация онлайн-игры

Для полной версии используйте Render: проект содержит постоянный Node.js/WebSocket-сервер, который нельзя запустить как обычный статический сайт Netlify. Файл `render.yaml` уже настроен; при создании Render Blueprint достаточно выбрать репозиторий. Если репозиторий содержит всю папку `Playground`, укажите корневую директорию `fruit-fuse-online`.

## Netlify

`netlify.toml` публикует правильную папку `public` и устраняет ошибку 404. При ручной загрузке через Netlify Drop перетаскивайте именно папку `public`, внутри которой лежит `index.html`.

Чтобы оставить интерфейс на Netlify, сначала разместите игровой сервер на Render, затем укажите его адрес в `public/runtime-config.js`:

```js
window.CORE_BELOW_SOCKET_URL = "wss://ВАШ-СЕРВЕР.onrender.com/socket";
```

После этого заново загрузите папку `public` на Netlify. Без внешнего WebSocket-сервера страница откроется, но онлайн-комнаты и обучение работать не будут.
